# Proyecto Framework Spring AI + ChatModel OpenAI

En este proyecto desarrollaremos un agente IA con los Frameworks de SpringBoot y SpringAI e incluiremos OpenAI.

## Requisitos del proyecto
- **Java 17 o superior**
- **Framework: SpringBoot  Mayor de v3.5.X o menor v4.x.x**
- **Integración: SpringAI, OpenAI**
